# SafeHer – Women Safety App

## 📱 About the Project
SafeHer is an Android-based safety application designed for women, with a special focus on supporting visually impaired users through voice-enabled and automated emergency features.

## 🚀 Features
- SOS Alert with Live GPS Tracking
- Facial Emotion Detection (Fear/Distress)
- Voice Guidance using Text-to-Speech (TTS)
- Shake Detection for Emergency Activation
- Fake Call Feature for Safety Situations
- Accessibility support for visually impaired users using voice commands

## 🛠 Technologies Used
- Java
- XML
- Firebase
- TensorFlow Lite
- ML Kit
